# wewi 1.2.0

## 한국어

**1.1.2 및 이전 버전 사용자는 1.2.0 DMG를 다운로드하여 직접 설치해야 합니다.** 이전 Sparkle 개인키를 사용할 수 없어 새 업데이트 키로 전환했습니다. 기존 버전의 업데이트 알림은 직접 다운로드하는 릴리스 페이지로 안내합니다. 1.2.0부터는 새 키로 후속 업데이트를 제공합니다.

- 위젯 관리 화면을 카드 목록, 검색, 표시 필터 및 별도 편집 화면으로 개선했습니다.
- 위젯을 드래그하는 동안 배치 미리보기를 표시합니다. 선택적으로 24pt 격자에 맞출 수 있으며 기본값은 자유 배치입니다.
- 위젯별 웹사이트 모드(자동·모바일·태블릿·데스크톱)를 추가했습니다. 자동 모드는 너비 600pt/1024pt를 기준으로 User-Agent를 선택합니다.
- 크기 변경으로 웹사이트 모드가 달라질 때 자동 새로고침하는 옵션을 추가했습니다. 기본값은 꺼짐이며, 기존 위젯은 데스크톱 모드를 유지합니다.
- 위젯 메뉴에서 해당 웹사이트의 쿠키를 확인 후 삭제할 수 있습니다. 공유 도메인 쿠키를 사용하는 다른 위젯에도 영향을 줄 수 있습니다.
- MacAppEssentials 기반 설정, 메뉴, 시작 시 실행, 업데이트 화면과 한국어·영어 온보딩을 적용했습니다.
- 이용약관과 개인정보 처리방침, 선택적 충돌 보고 기능을 추가했습니다. 충돌 보고는 기본 꺼짐이며 동의 후 다음 실행부터 적용됩니다.
- Icon Composer의 새 앱 아이콘을 적용했습니다.

기존 위젯 설정은 유지됩니다. 업데이트 후 최초 실행 시 온보딩과 약관 동의가 표시됩니다.
웹사이트의 모바일·태블릿 지원 여부는 사이트에 따라 다르며, 화면 모드 변경 시 재생이나 입력이 중단될 수 있습니다.
macOS 13 이상을 지원하며 Apple Silicon과 Intel용 파일을 별도로 제공합니다.

## English

**Users of 1.1.2 and earlier must download and install the 1.2.0 DMG manually.** The previous Sparkle private key is unavailable, so this release uses a new update key. The update notice in older versions links to the release page for a manual download. Future updates from 1.2.0 will use the new key.

- Redesigned widget management with summary cards, search, visibility filtering, and a separate editor.
- Added a placement preview while dragging and optional 24-point grid snapping. Free placement remains the default.
- Added per-widget Automatic, Mobile, Tablet, and Desktop website modes. Automatic mode selects a User-Agent at 600/1024-point width thresholds.
- Added optional reloads when resizing crosses a device-mode threshold. This is off by default; existing widgets retain Desktop mode.
- Added website cookie removal with confirmation. Shared domain cookies can affect other widgets using the same website.
- Integrated MacAppEssentials settings, menus, launch at login, update controls, and English/Korean onboarding.
- Added Terms, Privacy Policy, and optional crash reporting. Reporting is off by default and consent changes apply on the next launch.
- Updated the app icon using Icon Composer.

Existing widget settings are preserved. Onboarding and Terms acceptance appear on the first launch after updating.
Mobile/tablet website support varies by site; mode changes and reloads may interrupt playback or unsaved input.
Requires macOS 13 or later. Separate Apple Silicon and Intel downloads are provided.
